# Вектор климата — сайт векторклимата.рф

Статический одностраничный сайт без сборки: HTML + CSS + чистый JavaScript.
Открывается любым веб-сервером (или хостингом статики: Netlify, Vercel, GitHub Pages, обычный хостинг).

## Структура

```
index.html            главная страница (все разделы)
privacy.html          политика конфиденциальности (шаблон)
assets/css/style.css  дизайн-система и все стили
assets/js/config.js   ← КОНТАКТЫ И НАСТРОЙКИ (заполнить)
assets/js/main.js     меню, анимации, галерея, форма
assets/img/           оптимизированные фото (webp + jpg, несколько размеров), favicon, og.jpg
_source/              исходные фото из материалов (не публикуются)
robots.txt, sitemap.xml
```

## Перед запуском заполнить

1. **`assets/js/config.js`** — телефон, ссылка на MAX, режим работы (сейчас «Пн–Пт»), зона выезда,
   рейтинг на Авито. Пока поле пустое, на сайте показывается placeholder (подчёркнут пунктиром).
   **Отзывы** вписываются туда же в массив `reviews` — текстом или скриншотами; пока он пустой,
   в карусели стоят шаблонные карточки.
2. **Обработчик формы** — `formEndpoint` в том же файле (URL, принимающий POST с JSON).
   Без него форма показывает «Заявка отправлена» и предлагает продублировать заявку в MAX,
   но на сервер ничего не уходит.
3. **Факты рядом с формой** (`index.html`, ищите `class="ph"`): год начала работы и срок гарантии.
4. **`privacy.html`** — реквизиты оператора персональных данных.
5. Для SEO телефон лучше продублировать прямо в HTML (сейчас он подставляется скриптом).

## Локальный просмотр

```bash
python3 -m http.server 5174
```

и открыть http://127.0.0.1:5174

## Фото

Все фото — реальные объекты из профиля Авито. Чтобы добавить новое: положить исходник
в `_source/`, сделать версии 480/800/1280 px в webp и jpg и добавить `<figure class="work …">`
в раздел `#works`.
